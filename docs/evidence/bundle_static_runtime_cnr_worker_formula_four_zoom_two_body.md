# Static + Runtime Proof: ColorNoiseReduction Worker Formula

## Scope

This bundle narrows `CLM-DENOISE-002` after
`bundle_static_runtime_denoise_route_cnr_parameters_four_zoom.md`.

It proves the live `ColorNoiseReduction` worker envelope for Unit-1
four-focal profile-3 bridge-HDR renders plus an exact-35mm Unit-2 control:

- Unit-1 `28mm` `L16_02130`
- Unit-1 `35mm` `L16_03041`
- Unit-1 `70mm` `L16_03434`
- Unit-1 `150mm` `L16_02285`
- Unit-2 exact `35mm` `L16_01956`

This was not a full closure of `CLM-DENOISE-002`: at this evidence stage the
public origins/names for the internal CNR parameter vectors remained open, and
the `0x309270 -> 0x309d50` matrix helper was bounded as the live
static/runtime helper but not yet rewritten as a standalone clean-room
Jacobi/SVD formula. The later
`bundle_static_runtime_cnr_public_vector_origins_four_zoom_two_body.md` proof
closes the vector-origin gap, and the later
`bundle_static_runtime_cnr_matrix_helper_svd_four_zoom_two_body.md` proof
closes the matrix-helper gap.

## Worker Formula

For a source tile of `N` vec4 pixels `p = (p0, p1, p2, p3)`, the worker
accumulates:

```text
S2 = sum([p0*p0, p1*p1, p2*p2, p3*p3])
C  = sum([p0*p1, p0*p2, p1*p2, 0])
A  = sum(p3)
AP = sum(p3 * [p0, p1, p2, p3])
```

The parameter block generated by `0x307ee0` contains:

```text
low      = low_endpoint / high_endpoint
levelVar = ldexp((xmm0_arg * xmm1_arg)^2, -2 * level)
V10      = param[0x10..0x1f]
V20      = param[0x20..0x2f]
V30      = param[0x30..0x3f]
V40      = param[0x40..0x4f]
```

For the sampled live profile-3 renders, `xmm0_arg = xmm1_arg = 1.0`,
`high_endpoint = 1023`, Unit-1 uses `low_endpoint = 42`, and Unit-2 exact
35mm uses `low_endpoint = 43`. `levelVar` is a reciprocal power of four; the
runtime sample set observed `1/256` and `1/64`.

The worker computes the noise/shaping vector:

```text
meanA = A / N
noise = (meanA * V40
       + ((meanA * low + ((1 - low) / N) * AP * V10) * V30))
       * (levelVar * V20)
```

`verify_cnr_formula.py` recomputes this from captured source-tile bytes and
requires exact float32 equality against the live `rbp-0x230` vector. All
complete samples pass.

The worker then uses `rsqrtps(noise)` to normalize the RGB second-moment
matrix passed to `0x309270`:

```text
E2 = S2 / N
EC = C / N
r  = rsqrtps(noise)

M = [
  [E2[0]*r0*r0, EC[0]*r0*r1, EC[1]*r0*r2],
  [EC[0]*r0*r1, E2[1]*r1*r1, EC[2]*r1*r2],
  [EC[1]*r0*r2, EC[2]*r1*r2, E2[2]*r2*r2],
]
```

The verifier recomputes this matrix using the runtime-captured reciprocal
sqrt stack and captured source tiles. The maximum absolute difference is
`0.25`, with relative error under the verifier's `2e-7` gate; the absolute
delta is expected because large matrix entries amplify the final float32
rounding/`rsqrtps` approximation.

`0x309270` consumes `M` as doubles with mode `0x14`, normalizes by maximum
absolute matrix entry, and calls `0x309d50`. The caller then derives three
vec4 rows from the helper output and `sqrt(noise)`.

For each destination/current pixel `q`, the final live store formula is:

```text
q' = q0 * row_from_p0 + q1 * row_from_p1 + q2 * row_from_p2
```

The alpha lane is zeroed by construction. Across 60 captured store samples,
the verifier's maximum difference between the recomputed value and live
`xmm3` at the store is `5.19e-09`.

## Admission

This is a `CLM-DENOISE-002` partial-strengthening:

- admitted: live CNR worker accumulation, noise/shaping vector formula,
  normalized 3x3 helper-input matrix, and final transform-store formula;
- admitted: Unit-1 four-focal low endpoint `42/1023` and Unit-2 exact-35mm
  low endpoint `43/1023` in this CNR worker;
- admitted: sampled `levelVar` values follow the static
  `ldexp((xmm0*xmm1)^2, -2*level)` reciprocal-power-of-four rule;
- superseded by later proof: public origins/names for `V10`, `V20`, `V30`,
  and `V40`;
- superseded by later proof: clean-room derivation of
  `0x309270 -> 0x309d50` as a named standalone matrix/Jacobi/SVD helper;
- superseded by later proof: selector cause for the Unit-2 exact-35mm extra
  `0x2fd070` denoise sibling arm.
