# Editor mode-1 DOF layered compositor and large-radius resampler

## Result

The installed mode-1 depth-of-field path is formula-closed from its signed
blur-coordinate image through layer construction, neighbor-boundary opacity,
per-layer blur, and reverse-order premultiplied source-over composition.
This bundle also closes the previously unresolved large-diameter branch: it
uses a downsample/filter/upsample policy with an exact 64-phase cubic B-spline
resampler, signed 16.16 coordinates, and per-tap edge clamping.

Runtime scope is one Unit-1 `28mm` profile-3 RenderType-1 treatment with
renderer mode `1`, `MaximumInFocusBlurPixels=9`, public `f_num=2`, and public
center-derived `focus_depth=6020.888671875 mm`. Installed-static formulas are
binary/body/focal independent for the pinned `libcp.dylib`. Modes `2/3/4`,
depth type `1`, other-body/focal runtime, the static auxiliary-color branch,
and a nonempty secondary-coordinate layer remain outside this admission.

## Layer table

For the live depth type `0`, `0x2c1ad0` quantizes the signed per-pixel blur
coordinate range with `floor(lower)` and `ceil(upper)`, retains overlapping
geometric bins

```text
... [-8,-4], [-4,-2], [-2,-1], [-1,-0],
    [0,1], [1,2], [2,4], [4,8] ...
```

and prepends sentinel `[first.lower-1, first.lower]`. A regular bin has odd
diameter

```text
D = 2*ceil(abs(bin.upper)) + 1
```

while the sentinel uses `2*ceil(abs(first.lower))+1`. The 32 retained runtime
tables replay exactly; 131 retained records and the complete call census cover
diameters `{1,3,5,9,17,33,65,129}`. Binary search assigns every primary depth
pixel to exactly one record:

```text
record = upper_bound(record.lower <= depth) - 1
```

## Neighbor opacity

Target records are processed from highest to lowest table index. For target
`T=i`, `0x2a42f0` gathers source records `i+1`, `i-1`, and `i` when present.
For source `S`, the live depth-type-0 transition is binary32:

```text
k = floor(log2(T.diameter))
q = max(1 - 0.1*k, 0.1)
span = (S.upper - T.upper) * q
threshold = T.upper + span

if S.upper > T.upper:
    w = max(0, threshold - depth) / span
else:
    w = 1

sparse = [source.r, source.g, source.b, 1] * w
```

All 64 retained runtime pixels replay bit for bit: 23 use the ramp and 41 are
direct copies. The complete call relation census is `1883` lower, `2613`
equal, and `1883` greater. Installed depth type `1` substitutes coefficient
`0.2`, but that configuration was not runtime exercised here.

## Large-diameter path

For source dimensions `W,H`, rectangle `R=[x0,y0,x1,y1]`, and binary32
arithmetic:

```text
s = max(maxD/D, min(W,10)/W, min(H,10)/H)
scaled_width  = trunc((x1-x0)*s)
scaled_height = trunc((y1-y0)*s)
sx0 = trunc(x0*s)
sy0 = trunc(y0*s)
inv = 1/s

down.offset = [sx0*inv-x0, sy0*inv-y0]
down.scale  = [inv, inv]

scaled_D = trunc(D*s)
uniform_disk(radius=floor((scaled_D-1)/2))
separable_gaussian5

up.offset = [x0*s-sx0, y0*s-sy0]
up.scale  = [s, s]
```

Each offset/scale float is promoted to double for `0x2b2be0`. The verifier
replays 256 retained calls without mismatch: 128 down and 128 up, with paired
coverage for `D={17,33,65,129}` including nonzero tile origins.

## Cubic resampler

The scalar basis is the centered cubic B-spline:

```text
B(x) = (3*|x|^3 - 6*|x|^2 + 4)/6, |x| < 1
     = (2-|x|)^3/6,                1 <= |x| < 2
     = 0,                           otherwise
```

For phase `p in [0,63]`, `t=p/64`, the installed table stores four vec4-
replicated binary32 weights:

```text
[B(t+1), B(t), B(1-t), B(2-t)]
```

Offsets and scales first become signed 16.16 values by truncation:

```text
O = trunc(offset * 65536)
S = trunc(scale  * 65536)
q = O + destination_coordinate*S
base  = q >> 16
phase = (q >> 10) & 63
```

Each axis samples `base-1, base, base+1, base+2`. Every tap coordinate is
independently clamped to the source rectangle; there is no border
renormalization. Horizontal four-tap filtering feeds a four-row cache, then
the same four weights are applied vertically. The vec4 accumulation order is
`((tap0*w0 + tap1*w1) + tap2*w2) + tap3*w3` in packed binary32.

## Composition

After filtering one target layer, `0x2a5460` applies premultiplied source-over
in reverse table order:

```text
output = blurred_layer + (1 - blurred_layer.a) * prior_output
```

The installed three-neighbor gather and source-over instruction sequences are
byte-pinned by the verifier. Together with the exact layer constructor,
transition replay, branch census, disk proof, generated Gaussian, scaled
resampler, and reverse traversal, this closes the tested mode-1 layered /
occlusion compositor formula.

## Scope guards

- Runtime formula/incidence scope: Unit-1 `28mm`, profile 3, RenderType 1,
  renderer mode 1, the treatment named above.
- Installed-static formula scope: pinned x86_64 `libcp.dylib` only.
- Runtime `b4` was always zero. Its installed optional source-RGB scalar
  multiply is static-only here.
- Both `b5=0` and `b5=1` contexts occurred, but retained secondary coordinate
  vectors were empty. Nonempty secondary fill remains unexercised.
- The treatment used depth type `0` and equal first/second filter rectangles.
