# Parity Blockers

This file lists only the unknowns that still block a clean-room Lumen replacement whose merge quality is good enough to judge against real Lumen output.

## Rule

If a missing fact could plausibly cause:

- ghosting
- trails
- contributor misalignment
- wrong camera participation
- wrong framing or crop behavior

then it is a parity blocker.
