# Parity Spec Folder

This folder is for future section-by-section parity spec documents.

Each section file should cover one subsystem only, for example:

- `01_INPUT_FORMATS.md`
- `02_CAMERA_PARTICIPATION.md`
- `03_CALIBRATION.md`
- `04_PER_CAMERA_ISP.md`
- `05_WARP_COORDS.md`
- `06_MERGE.md`
- `07_OUTPUT_AND_VALIDATION.md`

Use `SECTION_TEMPLATE.md` when creating a new section.
